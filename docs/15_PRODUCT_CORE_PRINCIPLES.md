# TianKey 产品核心原则

## 项目定位

TianKey 是个人 BLE 手机车钥匙系统。

目标结构：

Flutter APP
↓
BLE通信
↓
ESP32
↓
车辆控制接口

## 重要约束

1. 不是简单按钮Demo。
2. 不是只实现锁车、解锁、寻车。
3. 必须模拟完整APP使用流程。
4. 必须覆盖权限、状态、异常场景。
5. APP逻辑完整后，再进入真实ESP32联调。

## 开发顺序

Phase 1:
项目记忆与需求整理

Phase 2:
APP完整流程模拟

Phase 3:
BLE通信接入

Phase 4:
ESP32真实控制

Phase 5:
最终APK验证

## AI开发原则

任何AI进入项目必须先理解：

- 产品目标
- 当前状态
- 已完成内容
- 下一步任务

禁止脱离项目上下文重新设计。

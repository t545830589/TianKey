# TianKey Acceptance Checklist

版本：V1.0

目的：
作为最终 APK 验收标准，防止只完成简单控制按钮。

## 一、核心目标

- [ ] APP 可以在没有真实 ESP32 时完整模拟最终流程
- [ ] 模拟逻辑与真实 BLE 逻辑分离
- [ ] 后续可以替换为真实 ESP32 通信

## 二、启动与连接

- [ ] 启动页面
- [ ] 蓝牙页面
- [ ] 扫描设备
- [ ] 发现车辆
- [ ] 连接车辆
- [ ] 自动连接
- [ ] 断开连接
- [ ] 重新连接

## 三、权限系统

- [ ] 管理员登录
- [ ] 临时借车登录
- [ ] 密码验证模拟
- [ ] 首次授权
- [ ] 权限判断
- [ ] 临时权限过期

## 四、车辆功能

- [ ] 锁车模拟
- [ ] 解锁模拟
- [ ] 寻车模拟
- [ ] 车辆状态显示

## 五、系统功能

- [ ] 时间同步
- [ ] 时间同步失败处理
- [ ] 设置页面
- [ ] 密码修改
- [ ] 临时借车密码
- [ ] 授权状态
- [ ] 设备信息

## 六、高级功能

- [ ] 日志系统
- [ ] 日志自动清理
- [ ] 自动落锁设置
- [ ] 管理员迁移
- [ ] 恢复出厂

## 七、禁止验收标准

以下情况不算完成：

- 只有锁车解锁按钮
- 没有权限流程
- 没有异常流程
- 没有模拟状态机
- UI完成但逻辑缺失

# TianKey V11 项目规则

## 项目定位
TianKey V11 是 BLE 手机车钥匙系统，不是简单遥控APP。

架构目标：
Flutter APP ↔ BLE ↔ ESP32 ↔ 车辆控制线路

## 开发原则
1. 第一阶段先完成完整模拟APK。
2. 模拟APK必须覆盖界面、逻辑、权限、连接流程、异常流程、日志、自动连接、时间同步、车辆指令模拟。
3. 第二阶段再替换真实ESP32 BLE通信。
4. 不允许只制作UI Demo。
5. 不允许遗漏目标文档中的使用场景。

## 权限原则
- 单APK设计。
- 管理员模式保留。
- 临时用户权限独立管理。

## 代码管理原则
任何修改必须记录：
- 修改原因
- 对应功能
- 对应场景
- 影响文件

删除文件前必须经过 FILE_MAP 分析确认。

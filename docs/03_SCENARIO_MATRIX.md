# TianKey Scenario Matrix

版本: V1.0

## 目的

记录完整用户场景，防止开发遗漏功能。

## S001 首次安装

流程:
- 打开APP
- 初始化系统
- 进入未绑定状态

结果:
用户需要进行车辆绑定。

## S002 扫描车辆

流程:
- 开启蓝牙
- 扫描附近设备
- 显示车辆信息

## S003 身份选择

用户选择:
- 管理员连接
- 临时用户连接

## S004 管理员绑定

流程:
- 密码验证
- 身份确认
- 保存管理员状态

## S005 自动连接

流程:
- APP启动
- 搜索授权车辆
- 自动恢复连接

## S006 车辆控制

控制:
- 锁车
- 解锁
- 寻车
- 升窗
- 降窗
- 后备箱

## S007 临时借车

限制:
只能使用授权范围内功能。

## S008 异常流程

包括:
- 蓝牙失败
- 认证失败
- 连接断开
- 权限过期

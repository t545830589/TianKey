# TianKey Scenario Matrix

版本: V1.1

目的:

记录最终 APK 必须模拟的完整用户场景，防止只实现简单车辆按钮。

# S001 首次安装

流程:
- 打开 APP
- 初始化系统
- 创建本地状态
- 进入未绑定状态

# S002 蓝牙与车辆发现

流程:
- 开启蓝牙
- 扫描设备
- 发现车辆
- 显示设备信息
- 准备连接

# S003 连接流程

流程:
- 请求连接
- 建立通信状态
- 连接成功
- 连接失败处理

# S004 管理员流程

包括:
- 管理员登录
- 密码验证
- 首次授权
- 权限确认

# S005 临时借车流程

包括:
- 临时密码验证
- 临时授权
- 权限限制
- 到期失效

# S006 自动连接

包括:
- APP启动自动搜索
- 已授权车辆恢复连接
- 连接失败重试

# S007 车辆控制

包括:
- 锁车
- 解锁
- 寻车
- 车辆状态反馈
- 后续 ESP32 指令映射

# S008 时间同步

包括:
- 自动同步
- 同步成功
- 同步失败处理

# S009 设置与管理

包括:
- 密码修改
- 临时借车密码
- 自动落锁设置
- 设备信息
- 授权状态

# S010 日志系统

包括:
- 操作记录
- 异常记录
- 日志自动清理

# S011 异常恢复

包括:
- 蓝牙失败
- 认证失败
- 连接断开
- 重新连接
- 权限过期
- 恢复出厂
- 管理员迁移

# 验收原则

不能只完成锁车、解锁、寻车按钮。

必须完整模拟最终 APP 的流程、权限、连接和异常状态。

# Feature Code Map

## Purpose
建立目标 APK 功能与真实代码之间的长期映射。

规则：

功能
↓
页面/UI
↓
代码文件
↓
验证状态
↓
完成证据
↓
下一步

禁止只根据文件名判断完成状态，必须有代码和验证依据。

---

## Evidence Tracking Rule

每个功能必须记录：

- 代码是否存在
- 运行是否验证
- 硬件/真实环境是否验证
- 验证结果在哪里记录
- 是否存在阻塞问题

代码存在 ≠ 功能完成。

## Completion Rule

功能只有满足以下条件才能标记完成：

1. 目标明确
2. 代码位置明确
3. 运行验证完成
4. 验证证据记录
5. 下一步不存在阻塞问题
